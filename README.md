# WordSelection

**Select words the same way, wherever you write.**

Ever double-clicked part of a web address and ended up selecting the whole thing? WordSelection makes dots and other punctuation act as word boundaries. Double-click `example.com` and you can select `example` or `com` instead of the entire address. The same approach works when you select text with the keyboard or drag after a double-click.

## Download

Download the latest `WordSelection-macOS-AppleSilicon.zip` from [Releases](https://github.com/MaxUSB/word-selection/releases/latest). Unzip it and move `WordSelection.app` to Applications. Requires an Apple Silicon Mac; an Intel Mac cannot run this release. This app is not notarized by Apple, so macOS may ask you to confirm the first launch.

## Get started

1. Open `WordSelection.app`. If macOS blocks the first launch, Control-click the app, choose **Open**, and confirm. You may also need to allow it in **System Settings → Privacy & Security**.
2. Look for the text-cursor symbol in the menu bar at the top of the screen. WordSelection lives there, not in the Dock.
3. Click the symbol and turn on **«Выделение по словам»** (*Select by words*). If asked for permission, open **System Settings → Privacy & Security → Device Management and Data Access** (the name may vary by macOS version), allow WordSelection, then turn the menu option on again.

## Use it

- **Double-click** a word to select it without including an adjacent dot. Keep the mouse button pressed and drag to select more words.
- Press **Option + Left/Right Arrow** to move between words. Hold **Shift** as well to extend or shrink the selection.
- Click the menu bar symbol and turn **«Выделение по словам»** off whenever you want your Mac's usual selection behavior back. Choose **«Выход»** (*Quit*) to close the app.

WordSelection works in apps that allow it to adjust text selection. Some text fields do not, so they may continue to select words in their usual way.
